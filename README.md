# Parenthese for Unraid

Community Apps template for [Parenthese](https://github.com/IliesAllali/parenthese), a family tree you host yourself.

The template runs the single-container image `ghcr.io/iliesallali/parenthese-aio` (PostgreSQL, API and web app). Map a port and an appdata folder, start it, and open the web UI. There is nothing else to fill in: the database and keys are created in the appdata folder on first start. Back up that folder.
